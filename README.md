# RegFinder V1

Static GitHub Pages-ready prototype.

## Included
- Modern responsive landing page
- Registration search/filter demo
- Registration product cards and detail modal
- Tiered service-fee calculator
- Transparent source/service/total price breakdown
- Finder enquiry form (localStorage)
- Vehicle-age warning
- Clear independent-service disclaimer
- Example inventory only

## Important
This build intentionally does NOT scrape DVLA. DVLA's Personalised Registrations website terms prohibit data-mining/robots and republication/resale of its website content without permission. Connect an authorised inventory source/dealer arrangement before enabling live purchasing.

## Publish
Upload `index.html` to a GitHub repository and enable GitHub Pages from the repository settings.
